# Release notes — DVM 108: zichtbare secundaire bronknoppen

Datum: 22 september 2026

In DVM-bronbeheer waren secundaire knoppen op witte bronkaarten functioneel aanwezig maar visueel vrijwel onzichtbaar, omdat zij de witte tekststijl van de donkere topbalk erfden.

De kaartcontext heeft nu een eigen secundaire knopstijl:
- witte achtergrond;
- blauwe rand;
- blauwe tekst;
- lichte hoverstatus.

Dit maakt onder andere **Voeg JSON toe** bij DRIP totaal direct zichtbaar. De wijziging raakt alleen de presentatie; import- en rekenlogica zijn ongewijzigd.
