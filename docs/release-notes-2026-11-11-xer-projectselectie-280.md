# BIdashActual 2.80, Primavera XER projectselectie

Primavera toonde een leeg scherm Import Project Options bij het importeren van een XER. De export bevat nu de PROJECT-velden voor een volledige projectexport en een OBS waar de project-WBS naar verwijst. De exportmelding toont de project-ID.

Gecontroleerd met een regressietest en een onafhankelijke lezer. De gebruikersbron en het projectselectiescherm in Primavera P6 Professional zijn nog niet getest.
